Codewars Solutions

My solutions to "Codewars" (https://www.codewars.com/) kata, written while practicing problem solving and improving my programming skills.

This repository is also a long-term record of my progress. The goal is not only to keep the final solutions, but to be able to look back months or years later and see how my approach to problems has evolved.

Languages

Solutions may be written in different languages depending on the kata and what I am currently studying:

- PHP
- C
- JavaScript
- TypeScript
- SQL
- Python

Repository Structure

Katas are organized primarily by their Codewars difficulty:

codewars/
├── 4-kyu/
├── 5-kyu/
├── 6-kyu/
├── 7-kyu/
└── 8-kyu/

Each kata may have its own directory containing the solution and, when useful, additional notes or tests.

Example:

4-kyu/
└── strip-comments/
    └── solution.php

Purpose

This repository is mainly for:

- practicing problem solving;
- strengthening programming fundamentals;
- experimenting with different approaches;
- revisiting older solutions;
- tracking improvement over time.

A solution that looks simple today may have been difficult when I first solved it. Likewise, an older solution may eventually reveal opportunities for improvement.

That is part of the purpose of keeping this repository.

Code Quality

The solutions are not necessarily intended to represent my best possible implementation.

Some solutions may be intentionally kept close to the way I originally solved the problem so that the repository preserves a record of my learning process.

Over time, I may revisit older solutions and improve them.

Progress

Difficulty levels and languages will evolve naturally as I continue solving kata.

The repository is primarily a personal learning log rather than a collection of optimized or canonical solutions.
